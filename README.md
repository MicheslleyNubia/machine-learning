# Validação de Modelos com Machine Learning

## Objetivo

Projeto desenvolvido para estudo de técnicas de treinamento, validação e avaliação de modelos de Machine Learning utilizando Python e Scikit-Learn.

## Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Scikit-Learn
- Jupyter Notebook

## Conceitos Praticados

- Separação de dados para treino e teste
- Decision Trees
- Avaliação de acurácia
- Cross Validation
- K-Fold
- Stratified K-Fold
- Validação de modelos

## Dataset

Dados simulados utilizados para análise e validação de modelos preditivos.

## Aprendizados

Durante este projeto pratiquei conceitos fundamentais de Machine Learning, com foco na avaliação e validação de modelos para garantir resultados mais confiáveis e consistentes.

## Observação

Projeto desenvolvido com objetivo de estudo e aprendizado dos conceitos de Machine Learning.
